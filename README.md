# 🛒 E-Commerce Sales Analysis

## 📌 Project Overview

The **E-Commerce Sales Analysis** project focuses on analyzing e-commerce sales data to understand sales performance, customer behavior, product performance, and business trends.

The project uses **Python and Jupyter Notebook** for data cleaning, exploratory data analysis, and data visualization.

The main goal is to transform raw e-commerce data into meaningful insights that can support better business decisions.

## 🎯 Objectives

* Analyze overall e-commerce sales performance
* Understand customer purchasing behavior
* Identify top-performing products
* Analyze category-wise sales performance
* Identify sales trends and patterns
* Perform data cleaning and preprocessing
* Explore relationships between different variables
* Create meaningful visualizations
* Extract useful business insights from the dataset

## 🛠️ Technologies Used

* **Python**
* **Jupyter Notebook**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**

## ⚙️ Installation & Setup

Follow the steps below to set up and run the project on your local system.

### 1️⃣ Install Python

Download and install Python on your system.

Verify the installation:

```bash
python --version
```

### 2️⃣ Clone the Repository

Open **Git Bash, Command Prompt, or VS Code Terminal** and run:

```bash
git clone https://github.com/rajasreekarthick/E-Commerce-Sales-Analysis.git
```

### 3️⃣ Navigate to the Project Folder

```bash
cd E-Commerce-Sales-Analysis
```

### 4️⃣ Create a Virtual Environment

Create a virtual environment for the project:

```bash
python -m venv .venv
```

### 5️⃣ Activate the Virtual Environment

#### Windows – Command Prompt

```cmd
.venv\Scripts\activate
```

#### Windows – PowerShell

```powershell
.venv\Scripts\Activate.ps1
```

#### Windows – Git Bash

```bash
source .venv/Scripts/activate
```

After successful activation, you should see:

```text
(.venv)
```

at the beginning of the terminal.

### 6️⃣ Upgrade pip

```bash
python -m pip install --upgrade pip
```

### 7️⃣ Install Required Libraries

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 8️⃣ Launch Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Jupyter Notebook will open automatically in your web browser.

### 9️⃣ Open the Project Notebook

Open:

```text
E-Commerce Sales Analysis.ipynb
```

Run the notebook cells step by step to perform the analysis.
